The Problem

Why We're Moving

The Insightly–Monday integration keeps breaking. We spend time fixing syncs instead of actually working.

We are leaving Insightly — permanently.

One tool less. One source of truth. No more broken syncs.

Demo 1

Lead → CRM → Offer

Lead comes in

  • School fills lead form on interactenglish.de
  • Submits → lead arrives in CRM Pipeline instantly
  • Syncs to Monday + Slack notification
  • Admin reviews in CRM — school, program, students, dates

Send an Angebot

  • CRM Pipeline → click Create Offer
  • Form pre-fills from lead data
  • Select programs, price auto-fills from Preisliste
  • Save & Send → school receives branded PDF by email

"Every lead lands in the pipeline automatically. Angebot out in 2 minutes."

Demo 3

TA Onboarding

Invite a TA → they complete onboarding → ready to work

Admin side

  • Teaching Artists → Invite TA → credentials generated
  • Onboarding page → all tasks + Nudge buttons
  • Training → online + offline completion tracking
  • Availability → calendar grid shows who's free

TA side

  • Logs in → dashboard shows onboarding checklist
  • Completes: personal details, payroll, school profile, documents, training
  • Uploads police check, measles cert, first aid
  • Sets weekly availability

"From invite to ready-to-work — everything in the portal."

Demo 4

Project Management

1. Teacher Infopack

  • Send infopack request to school contact
  • Teacher fills: rooms, school times
  • Submitted via portal — no email back-and-forth
  • Admin sees responses in project view
  • Make schedule (coming soon)

2. Staffing & Work Orders

  • Create work order → assign TA, school, dates, program
  • TA receives email + sees in portal
  • Accepts & signs digitally
  • Added to project automatically

3. Project Folder

  • Google Drive folder linked to project
  • Admin coordination checklist attached
  • TAs see their work order + project docs
  • Teacher sees project info + TA profiles (no internal docs)

"One project. Every person sees exactly what they need — nothing more."

Finance
